# LinkBox Brand & UI Asset Kit

Complete V1 design handoff for the LinkBox web app.

## Included
- Transparent full logo, symbol and wordmark
- SVG logo sources
- App icons from 16px through 1024px
- Favicons and Apple/PWA icon sizes
- Reusable functional UI SVG icons
- Brand color palette and CSS variables
- Tailwind-compatible theme snippet
- Typography guidance
- Approved mobile mockup references
- Web manifest and HTML metadata snippets
- Developer asset map

## Brand direction
Simple, mobile-first, Seedr-like clean cloud-storage vibe without copying Seedr branding.

## Primary palette
- LinkBox Blue: #0969F5
- Navy: #071A3A
- Background: #F6F9FE
- Surface: #FFFFFF
- Text: #0F1F3D
- Muted: #6B7A99
- Success: #12B76A
- Warning: #F79009
- Danger: #F04438

## Typography
Inter with system fallbacks. No font binaries are included.
