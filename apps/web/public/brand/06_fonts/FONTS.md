# LinkBox Typography

Primary: **Inter** (Google Fonts / system fallback)

Recommended weights:
- 400 Regular — body / metadata
- 500 Medium — controls
- 600 Semibold — section titles
- 700 Bold — headings
- 800 ExtraBold — LinkBox wordmark only when SVG/PNG logo is unavailable

Fallback:
`Inter, system-ui, -apple-system, "Segoe UI", Roboto, Arial, sans-serif`

Do not bundle font binaries in the repository unless licensing and hosting requirements are reviewed.
